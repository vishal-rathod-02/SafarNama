# 🚗 SafarNama – AI Powered Travel Planning Web Application

### Explore smarter journeys with AI-generated travel experiences across India ✨

---

# 📖 Overview

SafarNama is a modern full-stack travel planning web application that helps users generate intelligent travel roadmaps between destinations across India. The platform combines route planning, nearby attraction discovery, restaurant recommendations, and AI-powered trip generation to create a seamless and immersive travel experience.

Users can explore routes, calculate distance and duration, discover famous tourist places, and receive AI-generated travel summaries, highlights, and itineraries for their journey.

---

# ✨ Features

- 🗺️ Smart route generation between source and destination
- 📍 Discover nearby tourist attractions and famous places
- 🍽️ Restaurant and food place recommendations
- 🤖 AI-powered trip summaries and itinerary generation
- 🚗 Distance and travel duration calculation
- ⚡ Optimized backend with caching and fallback responses
- 📱 Fully responsive modern UI
- 🌍 India-focused travel planning experience

---

# 🧠 AI Integration

SafarNama integrates the **OpenAI API (`gpt-4o-mini`)** to generate:

- Travel summaries
- Trip highlights
- Day-wise itineraries

The AI system includes:

- Request caching
- Timeout handling
- Graceful fallbacks
- Optimized prompt engineering
